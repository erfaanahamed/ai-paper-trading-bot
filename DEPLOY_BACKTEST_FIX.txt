ANDROID / GITHUB DEPLOY
-----------------------
1. Extract this ZIP on your phone.
2. In the GitHub repository, use the main branch.
3. Upload the CONTENTS of this extracted folder to the repository root.
   Do not upload the ZIP itself and do not create an extra enclosing folder.
4. Keep the trading_engine folder intact. It must be directly beside app.py:
      app.py
      requirements.txt
      runtime.txt
      trading_engine/
          __init__.py
          backtest.py
          ...
5. Commit the upload to the same branch used by Streamlit.
6. In Streamlit Cloud, confirm Main file path is app.py, then reboot the app.
7. Run the backtest again.

IMPORTANT
---------
Do not upload only the Python files inside trading_engine/ to the repository
root. The folder name and its __init__.py are required for package imports.
