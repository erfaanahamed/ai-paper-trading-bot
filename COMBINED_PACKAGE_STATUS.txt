AI BRAIN — HYBRID SELF-LEARNING RESEARCH PACKAGE

This version connects causal OHLCV indicators, the rule-based strategy ensemble, a triple-barrier outcome labeler, a calibrated scikit-learn meta-model, walk-forward evaluation, and an expected-value/cost gate in the market scanner.

Paper/research only. A scan may remain WAIT/SKIP while data is stale, indicators are warming up, there is insufficient training data, the model fails its validation threshold, or the estimated net expected value is not positive. A loaded model is not automatically retrained on every scan; model refresh and completed-trade feedback orchestration remain future work.

Symbols are Yahoo Finance proxies, not broker quotes. Gold uses GC=F, Silver uses SI=F, and WTI crude uses CL=F. No broker orders, wallet connection, or live trading is included. There is no guarantee of profitability.

NEWS SOURCE UPDATE (V5): News Protection uses only Forex Factory/Fair Economy published weekly JSON feed at https://nfs.faireconomy.media/ff_calendar_thisweek.json. Only impact="High" (red-folder) events are accepted. No ShowMyTrades, third-party calendar, or uploaded CSV fallback is used. Feed refresh interval: 15 minutes. The published feed covers the current week; a successful cached result is used if refresh fails. If no valid feed/cache exists, News Protection blocks new entries. Forex Factory notices prohibit copying/redistribution of calendar data without written consent; this bot uses the public feed for local paper-trading protection and does not republish it.
